第 71 課：法語形容詞的性數一致與位置藝術

學會讓形容詞與名詞完美配合，並掌握 BAGS 法則

1 形容詞的性數一致基礎

法語形容詞必須與它所形容的名詞在性（陰性／陽性）和數（單數／複數）上保持一致。最基本的規則是在形容詞詞尾加上 -e 變為陰性，加上 -s 變為複數。例如：petit（陽性單數）→ petite（陰性單數）→ petits（陽性複數）→ petites（陰性複數）。特別注意：部分以 -e 結尾的形容詞，陰性形式與陽性相同，不需要再加 -e。

2 發音對照表

以下列出常見形容詞的陰性變化規則，請特別留意發音的變化：
• 以 -e 結尾的形容詞，陰性通常發音不變
• 以 -c 結尾的，陰性加 -he（如 sec → sèche）
• 以 -f 結尾的，陰性變為 -ve（如 afraid → frighté → frightée（例外））

陽性單數，以 /t/ 結尾（發音）
un chat petit（一隻小貓）
-petite /-petit/
陰性單數，加 -e 但發音不變
une robe petite（一件小連衣裙）
-gentil /-ʒɑ̃til/
陽性單數，以 /l/ 結尾
un garçon gentil（一個善良男孩）
-gentille /-ʒɑ̃til/
陰性單數，加 -e 但發音不變
une fille gentille（一個善良女孩）

📐 BAGS 法則——形容詞位置初探

法語形容詞的位置與中文不同，部分形容詞放在名詞前，部分放在名詞後。有一個實用的記憶口訣——BAGS 法則：

• Beauty（美）：beau, belle, joli(e), beau 等
• Age（年齡）：jeune, vieux/vieille, nouveau/nouvelle, ancien/ancienne 等
• Goodness（好壞）：bon(ne), mauvais(e), gentil(le), gentil 等
• Size（大小）：grand(e), petit(e), gros(se), long(ue) 等

除此之外的形容詞，通常放在名詞之後，例如：une voiture rouge（紅色的車）、un livre intéressant（有趣的書）。

BAGS 位置
名詞前，如 un grand homme
un beau jour
形容的是普遍概念而非具體特徵
非 BAGS 位置
名詞後，如 une table ronde
une voiture rouge
描述具體的物理特徵
位置影響語意
同一個形容詞放不同位置意思可能不同
un ancien ministre（前部長）vs un ministre ancien（年長的部長）
注意「前」與「古老」的差別
⚡ 重點對照——常見不規則陰性變化

許多常用形容詞的陰性變化並不規則，必須特別記憶：
• -er → -ère：cher → chère（昂貴的）
• -f → -ve：neuf → neuve（新的）、raf → rative（轉化的）
• -eil → -eille：joli → jolie（漂亮的）
• -ent → -ente：content → contente（開心的）
• -f → -ve：beau → belle（美麗的）

請特別注意 beau / bel / belle 這組形式：beau 用於陽性單數（consonant 開頭前用 bel），belle 用於陰性單數。

✏️ 小測驗

請先回答，再點擊「查看答案」

1. 下列哪一句的形容詞性數一致是正確的？
  • A. Elle est content.
  • B. Elle est contente.
  • C. Elles est contentes.
✅ 答案 B：se 是陰性單數，形容詞需加 -e 變成 contente。
2. 「un grand homme」中的 grand 放在名詞前，原因為何？
  • A. 因為它是 BAGS 法則中的 Size（大小）
  • B. 因為它是 BAGS 法則中的 Beauty（美）
  • C. 因為它是不規則形容詞
✅ 答案 A：grand 屬於 Size 類別，放在名詞前。
3. 「un beau jour」中beau 的正確陰性形式是？
  • A. beae
  • B. belle
  • C. beee
✅ 答案 B：beau 的陰性形式是 belle，發音與 bel 相同。
