第 84 課：方位動詞與空間搭配進階

掌握 monter / descendre / entrer / sortir 等動詞搭配方位介詞的精準用法

1 課程導論：動詞搭配空間表達

在第 83 課學過方位介詞（dans, sur, sous, devant, derrière, à côté de, entre 等）之後，本課將這些介詞與具方向性的動詞結合，讓你能夠用更豐富的語言描述「往哪裡去、從哪裡來、在什麼位置」。法語中有些動詞必須搭配特定介詞才能正確表達空間意義，這部分是本課的學習重點。

2 發音對照表：方位動詞搭配

以下列出本課核心動詞與其搭配的方位介詞，請特別注意動詞與介詞之間的聯誦（liaison）現象。

monter dans
/mɔ̃.te dɑ̃/，聯誦 d 與 dɑ̃ 連接
monter dans le train（登上火車）
descendre de
/de.sɑ̃dʁ də/，de 後接元音或 h 開頭字需聯誦
descendre de l'autobus（下車）
entrer dans
/ɑ̃.tʁe dɑ̃/，entrer 的 r 發法語喉音 R
entrer dans la salle（進入房間）
sortir de
/sɔʁ.tiʁ də/，注意 r 的發音位置
sortir de la maison（離開房子）
mettre sur
/mɛt syʁ/，sur 的元音 /y/ 要圓唇
mettre le livre sur la table（把書放在桌上）
plier sous
/pli.e su/，sous 的 s 發 /s/ 音
plier sous le poids（被重量壓彎）

💡 小技巧：動詞與介詞之間不要斷開，尤其是 monter dans、descendre de 這類常見搭配，聯誦會讓你的法語聽起來更自然流暢。

⚡ 重點對照：動詞搭配介詞的規律

法語中不同動詞搭配不同介詞，這是需要記憶的固定搭配，但背後有一些邏輯可以幫助你理解。

dans + 名詞
表示「進入某空間內部」，強調進入的動作
Je entre dans la classe.
dans 強調進入一個有邊界的空間
de + 名詞
表示「從某處出來」，來源方向
Je sors de la pièce.
de 表示離開或來源
sur + 名詞
表示「在……表面上」
Le livre est sur la table.
sur 接觸表面但不進入內部
sous + 名詞
表示「在……下方」
Le chat est sous la table.
sous 表示位置在另一物體下方
devant + 名詞
表示「在……前面」
Il se tient devant la porte.
devant 強調正面的位置關係
derrière + 名詞
表示「在……後面」
La voiture est derrière la maison.
derrière 強調背面的位置關係
✏️ 小測驗：動詞與介詞搭配

請先回答，再點擊「查看答案」

1. 「Je ____ de la voiture.（我從車上下來）」應填入哪個動詞？
  • A. monter
  • B. descendre
  • C. entrer
✅ descendre 表示「從高处或交通工具下來」，搭配介詞 de 表示來源。
2. 「Il met le vase ____ la table.（他把花瓶放在桌上）」空格應填哪個介詞？
  • A. dans
  • B. sur
  • C. sous
✅ sur 表示「在表面上」，花瓶是放在桌子表面而非桌子內部。
3. 下列哪一句的聯誦是正確的？
  • A. monter dan le train
  • B. monter dans le train（d 聯誦）
  • C. monter dans le train（不聯誦）
✅ dans 的 s 不發音，但當後面接元音開頭的字時，dans 的 s 需要聯誦發 /z/ 音，所以「dans le」讀作 /dɑ̃ l/。
4. 「 sortir de 」這個搭配中的 de 何時需要聯誦？
  • A. 永遠聯誦
  • B. 後接元音或 h mute 時聯誦
  • C. 從不聯誦
✅ de 後接子音開頭的字不聯誦（如 de la），後接元音或 h mute 時聯誦發 /d/ 音（如 de l'école）。
