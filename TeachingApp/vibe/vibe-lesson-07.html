Phase 2: Local Persistence

第 7 課：建立本地檔案儲存

利用 Node.js 模組在磁碟上讀取、寫入和刪除 JSON 檔，讓 Vibe 能持久化記憶

💾 為什麼需要本地檔案儲存？

Vibe Coding 的核心是讓 AI Agent 能「記著」用戶的偏好與歷史行為。使用本地檔案（如 JSON 檔）可讓程式在重新啟動後仍保留這些資訊。AI Agent 通過讀取或寫入這些檔案來實現記憶與狀態管理。

🤖 AI Agent 如何調用本地檔案？

AI Agent 透過內建的 FilesystemManager 模組，自動處理對 data/user_data.json 的讀寫。讀取時，它檢查檔案是否存在並格式正確；寫入時，它會序列化物件為 JSON 並覆寫內容。若失敗，會觸發錯誤回呼並記錄日誌，讓 Vibe 能重新調整行為。

🔬 深入解析

請以下列程式碼示範如何使用 Node.js 原生模組 fs 與 path 來安全地讀寫使用者資料檔案。同時加入錯誤處理與檔案鎖機制（簡單版），避免多個寫入操作衝突。

const fs = require('fs'); const path = require('path'); const DATA_FILE = path.join(__dirname, 'data', 'user_data.json'); async function readUserData() { try { const data = await fs.promises.readFile(DATA_FILE, 'utf8'); return JSON.parse(data); } catch (err) { if (err.code === 'ENOENT') return {}; // 檔案不存在，回傳空物件 console.error('讀取失敗:', err.message); throw err; } } async function writeUserData(userData) { try { await fs.promises.writeFile(DATA_FILE, JSON.stringify(userData, null, 2)); console.log('資料已成功儲存。'); } catch (err) { console.error('寫入失敗:', err.message); throw err; } }
🔧 Vibe 破裂診斷與修復

當 Vibe 報錯時，請檢查：1. 檔案路徑是否正確（使用 path.join 避免 OS 差異）；2. 檔案是否被其他程式鎖定；3. JSON 格式是否合法（可用線上驗證工具）。若發生權限錯誤，請確認執行者有 data 目錄的讀寫權。修復後重新啟動 AI Agent 即可恢復 Vibe。

✏️ 小測驗

請先回答，再點擊「查看答案」

1. 當使用者第一次執行程式，但 user_data.json 還不存在，readUserData() 應該回傳什麼？
  • A. null
  • B. 空物件 {}
  • C. 拋出錯誤
✅ 回傳空物件 {} 可讓 AI Agent 從零開始建立使用者資料，避免程式崩潰。
2. writeUserData() 遇到磁碟空間不足的錯誤時，最合適的處理方式是？
  • A. 忽略錯誤繼續執行
  • B. 記錄日誌並拋出錯誤給上層處理
  • C. 自動刪除舊檔案以騰出空間
✅ 應將錯誤傳遞給上層（例如 Vibe 診斷模組），讓系統能決定是否通知使用者或切換至備存策略。
