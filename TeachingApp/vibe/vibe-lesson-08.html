課程第 8 課：資料庫與 CRUD 操作

學習如何使用 NoSQL 資料庫持久化儲存應用資料

🗄️ 資料庫在 Vibe Coding 中的角色

在 Vibe Coding 的生態系統中，資料庫是 AI Agent 記憶與狀態管理的核心。它不僅用來儲存使用者資料、系統設定或應用狀態，更是讓應用從「一次性」轉為「持久化」的關鍵。NoSQL（如 MongoDB）因結構靈活、易於擴充，非常適合快速開發環境中的 AI Agent 應用。

🔬 深入解析

AI Agent 通常會透過 Mongoose 或 mongodb 等 ORM/ODM 工具來與 MongoDB 互動。它會先建立 Schema 定義資料結構，再執行 Create, Read, Update, Delete（CRUD）操作。當 Vibe 破裂時，常見的問題包括連接失敗、驗證錯誤、Schema 不符或索引缺失，這些都需要從連接字串、權限設定、資料格式等多方面診斷。

const mongoose = require('mongoose'); mongoose.connect(process.env.MONGODB_URI, { useNewUrlParser: true }); const User = mongoose.model('User', new mongoose.Schema({ name: String, email: String })); // 插入新使用者 new User({ name: 'Alice', email: 'alice@example.com' }).save() .then(() => console.log('使用者已儲存')) .catch(err => console.error('Vibe 破裂：', err.message));

  • A. Node.js 版本過低
  • B. MONGODB_URI 環境變數未設定或格式錯誤

✅ B. MONGODB_URI 環境變數未設定或格式錯誤是導致連接失敗的最常見原因，應先檢查 .env 檔案與連接字串正確性。
