🎯 Vibe Coding 中的核心角色：AI 作為 UI 設計引擎

v0 和 Bolt 這類 AI 原型工具，在 Vibe Coding 流程中扮演的是「快速視覺化」的核心角色。它們能將一句自然語言提示直接轉化為可運行的前端代碼，大幅縮短從想法到原型的時間。學習者不需要手動撰寫 HTML 或 CSS 結構，而是透過精準的 Prompt 來調教 AI 產生符合需求的元件組合。這不僅提升開發效率，更重要的是讓開發者能專注於「邏輯設計」而非「樣式細節」。當 AI 生成錯誤或不理想的 UI 時，診斷關鍵在於檢查 Prompt 是否足夠明確，以及是否指定了正確的框架（如 React）與元件庫（如 Tailwind）。

🧩 AI Agent 如何運用組件化思維生成 UI

AI Agent 在使用 v0 或 Bolt 時，會自動將使用者的 Prompt 拆解為多個可獨立運行的元件（Component），例如 Header、Hero Section、Call-to-Action Button 等。每個元件都由 AI 獨立生成並組合成完整的頁面。這意味著，若要修改按鈕顏色或文字位置，只需針對特定元件進行 Prompt 修正，而不需要重寫整個頁面。這種組件化思維是 Vibe Coding 高效能的关键——它讓 AI 成為一位懂設計的協作夥伴，而不是單純的文字翻譯器。學習者應習慣以「元件級別」思考 Prompt，例如生成一個「深藍色背景的 Call-to-Action 按鈕」而非只是「一個漂亮的按鈕」。

🛠️ 當 Vibe 破裂：如何診斷與修復 AI 生成的錯誤 UI

當 AI 產生的 UI 無法正常顯示或不符合預期時，常發生在Prompt 太模糊、未指定框架、或未說明風格導向。診斷步驟包括：首先檢查 AI 是否使用了正確的技術棧（例如是否誤用 Vue 而非 React）；其次確認是否缺少必要的依賴或樣式庫（如 Tailwind CSS 未正確引入）；再者觀察是否有重複或未封閉的標籤。修復策略是先簡化 Prompt，例如：「使用 React + Tailwind 生成一個單頁 Landing Page，包含標題、介紹段落、聯絡表單和三項功能圖標，配色為白色背景配藍綠色主調」，並明確指出元件之間的相對位置。這樣能減少歧義，提高生成準確性。

✏️ 小測驗：測試你的理解程度

請先回答，再點擊「查看答案」

1. 下列哪種 Prompt 最適合讓 AI 生成一個含功能圖標與按鈕的 Landing Page？
  • A. 幫我弄個漂亮的網頁
  • B. 使用 React 與 Tailwind 生成一個 Landing Page，包含三个功能項目（每項有 icon 與描述）、一個主要 CTA 按鈕，配色為深色主題
  • C. 寫一個 HTML 文件
✅ 選項 B 最成功，因為它指定了技術棧（React + Tailwind）、內容結構（三項功能+CTA 按鈕）、和主題風格（深色），使 AI 能明確理解需求。選項 A 過於模糊，缺乏具體要求；選項 C 雖提及技術類型，但未說明內容或結構，導致 AI 可能生成不完整或無關的代碼。
2. 當 AI 生成的 UI 無法顯示或佈局錯亂時，最可能的原因為何？
  • A. 你的電腦速度不夠快
  • B. Prompt 未指定框架或缺少必要樣式庫設定
  • C. AI 系統故障
✅ 正確答案是 B，因為 AI 生成 UI 高度依賴 Prompt 中所指定的技術環境（如 React、Tailwind、Styled Components 等），若未明確說明，AI 可能選用錯誤的架構或未套用正確樣式類，導致佈局錯誤。選項 A 是干擾項，AI 生成不依賴本地運算資源；選項 C 也極罕見，除非服務完全不可用，否則通常是使用者 Prompt 的問題。

請依序完成以下練習

  1. 1. 使用 Bolt 或 v0，輸入一句精確的 Prompt，生成一個 Landing Page，觀察其元件結構與樣式應用。
