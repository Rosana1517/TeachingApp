第 6 課：理解資料結構與 JSON 序列化

讓 AI Agent 準確傳遞與解析數據的關鍵橋樑

📦 為什麼需要 JSON？

在 Node.js 中，我們處理的數據通常是 JavaScript 物件（Objects）。但當這些數據要透過 HTTP 回應傳給前端，或是要存入檔案時，必須轉換成文字格式。JSON（JavaScript Object Notation）是 Vibe Coding 中最標準的資料交換格式。AI Agent 在生成 API 回應時，會自動將內部數據結構序列化為 JSON 字串，確保接收端能正確解讀。

🔬 深入解析

AI Agent 調用 JSON 技術通常涉及兩個核心方法：JSON.stringify() 用於將 JS 物件轉為字串（發送前），JSON.parse() 用於將收到的字串轉回物件（接收後）。當 Vibe 破裂出現 Unexpected token o in JSON at position 1 錯誤時，通常代表你試圖解析一個已經是物件的東西，或是接收到的內容不是合法的 JSON 格式。

// AI Agent 生成的典型 Node.js 程式碼片段 const data = { id: 1, name: "Agnes" }; // 發送回應時 res.setHeader('Content-Type', 'application/json'); res.status(200).send(JSON.stringify(data)); // 接收請求體時（需搭配 body-parser 或 express.json()） const parsedData = JSON.parse(req.body);
✏️ 小測驗

請先回答，再點擊「查看答案」

1. 當你在瀏覽器控制台看到 "Unexpected token < in JSON" 錯誤，最可能的原因是什麼？
  • A. 你的 JSON 物件太複雜了
  • B. 伺服器返回了 HTML 錯誤頁面而非 JSON
  • C. 你的電腦記憶體不足
✅ B. 伺服器發生錯誤（如 500 Internal Server Error），返回了 HTML 格式的錯誤訊息，但客戶端嘗試將其作為 JSON 解析。
2. 哪個方法用於將 JavaScript 物件轉換為 JSON 字串？
  • A. JSON.parse()
  • B. JSON.stringify()
  • C. JSON.convert()
✅ B. JSON.stringify() 負責序列化，將物件轉為字串。
