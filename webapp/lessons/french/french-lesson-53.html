LEÇON 53

第 53 課：法語主有代名詞的流暢運用

代替「主有形容詞 + 名詞」，讓句子更精簡自然

1 為什麼要學主有代名詞？

當你已經用過 主有形容詞（mon/ton/son…）來表達「我的、你的、他的…」之後，接下來要學會用主有代名詞來代替「主有形容詞＋名詞」，避免重複。例如：「Ce livre est à moi」可以簡化成「Ce livre est le mien。」這課將帶你掌握 le mien、la mienne、les miens、les miennes 等形式的變化與連讀。

2 發音對照表：主有代名詞

主有代名詞須與所取代的名詞在性別與數量上保持一致。以下是单數與複數、陽性與陰性的完整形式：
陽性單數：le mien /lə mjɛ̃/、le tien /lə tjɛ̃/、le sien /lə sjɛ̃/、le nôtre /lə nɔːtʁ/、le vôtre /lə votʁ/、le leur /lə lœʁ/
陰性單數：la mienne /la mjɛn/、la tienne /la tjɛn/、la sienne /la sjɛn/、la nôtre、la vôtre、la leur
陽性複數：les miens /le mjɛ̃/、les tiens /le tjɛ̃/、les siens /le sjɛ̃/、les nôtres /le noːtʁ/、les vôtres /le votʁ/、les leurs /le lœʁ/
陰性複數：les miennes /le mjɛn/、les tiennes /le tjɛn/、les siennes /le sjɛn/、les nôtres、les vôtres、les leurs

le mien
陽性單數第一-person，/ə/ 在聯誦時發 /ljɛ̃/
Ce stylo est le mien.（這支筆是我的。）
la tienne
陰性單數第二-person，重讀 /jɛn/
La voiture est la tienne.（這輛車是你的。）
les nôtres
複數形式（陽／陰同形），/nɔːtʁ/ 保持鼻化
Nos amis sont les nôtres.（我們的朋友是他們的。）
les leurs
複數形式，注意 /ʁ/ 最後不發音
Ces livres sont les leurs.（這些書是他們的。）
🎙 跟練時間

請跟著朗讀以下句子，注意「主有代名詞」前的冠詞（le/la/les）必須與名詞性別與數量一致，並留意聯誦與重音位置。

請跟著朗讀以下句子，注意「主有代名詞」前的冠詞（le/la/les）必須與名詞性別與數量一致，並留意聯誦與重音位置。

  • Ce sac est le mien. /sæk ɛ lə mjɛ̃/ —— 這個袋子是我的。
  • Cette robe est la tienne. /sɛt ʁob ɛ la tjɛn/ —— 這件裙子是你的。
  • Ces enfants sont les siens. /sɛ ɑ̃fɑ̃ sɔ̃ le sjɛ̃/ —— 這些孩子是他的（親生的）。
  • Nos chaises sont les leurs. /no ʃɛz sɔ̃ le lœʁ/ —— 我們的椅子是他們的。

💡 小技巧：練習時可先口語重複「主有形容詞＋名詞」，再改說「主有代名詞」，感受語句的精簡效果。

⚡ 重點對照：主有形容詞 vs. 主有代名詞

主有形容詞必須放在名詞前面並與名詞的性別、數量一致；主有代名詞則代替「名詞＋主有形容詞」，本身包含冠詞（le/la/les），需與被取代名詞的性別數量一致。

mon livre → le mien
陽性單數：形容詞加名詞 vs. 代名詞
J'ai lu ton livre. → C'est le tien.
注意 le/la/les 不能省略
ta voiture → la tienne
陰性單數：形容詞加名詞 vs. 代名詞
Elle cherche sa voiture. → Elle cherche la sienne.
陰性單數代名詞多一個 -e
nos amis → les nôtres
複數：陽／陰同形，重音落在倒数第二个音节
Ils sont nos amis. → Ce sont les nôtres.
nôtre/vôtre 保留重音符号以區分與主有形容詞
leurs idées → les leurs
複數代名詞，注意 /ʁ/ 通常不發音
Ce sont leurs idées. → Ce sont les leurs.
leurs 作形容詞時 /ʁ/ 發音，作代名詞時不發
✏️ 小測驗

請先回答，再點擊「查看答案」

1. 「Ce cahier est à moi.」可以用哪一個主有代名詞簡化？
  • A. le mien
  • B. la mienne
  • C. les miens
✅ cahier 是陽性單數，故用 le mien。
2. 下列哪一句主有代名詞與名詞的性別、數量不匹配？
  • A. Cette table est la sienne.
  • B. Ces fleurs sont les nôtres.
  • C. Ces fleurs sont le nôtre.
✅ fleurs 是複數陰性，代名詞應為 les nôtres，而不是 le nôtre。
3. 主有代名詞「les vôtres」對應的主有形容詞是哪一組？
  • A. votre / vos
  • B. ton / ta / tes
  • C. leur / leurs
✅ vôtre 來自兩人的「你們」，形容詞為 votre（單數）或 vos（複數）。
