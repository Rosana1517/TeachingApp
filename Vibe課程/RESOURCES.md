# 參考資源清單

## Node.js 與 JavaScript 執行環境

- [Node.js 官方入門指南](https://nodejs.org/en/learn/getting-started/introduction-to-nodejs) — 最權威的 Node.js 介紹，涵蓋 V8、Event Loop、模組系統等核心概念。
- [MDN: JavaScript 引擎工作原理](https://developer.mozilla.org/en-US/docs/Glossary/V8) — 深入了解 V8 的編譯與優化機制。
- [Node.js 官方文件](https://nodejs.org/docs/latest/api/) — API Reference，查閱所有內建模組。
- [Understanding Event Loop, Callbacks, Promises and Async/Await in JavaScript](https://www.freecodecamp.org/news/understanding-javascript-event-loop-promises-and-async-await/) — freeCodeCamp 的事件循環深度文章。

## NPM 與套件管理

- [NPM 官方文件](https://docs.npmjs.com/) — package.json、dependencies、scripts 的完整說明。
- [npm create](https://docs.npmjs.com/cli/v10/commands/npm-create) — npx 與專案初始化工具的使用方式。

## Next.js

- [Next.js 官方文件](https://nextjs.org/docs) — App Router、Server Components、API Routes 的完整文檔。
- [Vercel: Next.js Server-Side Rendering Explained](https://vercel.com/guides/nextjs-principles) — SSR vs CSR 的直覺理解。

## Git / GitHub

- [Git 官方教程](https://git-scm.com/book/zh-tw/v2) — 版本控制基礎。
- [GitHub Docs](https://docs.github.com/) — GitHub 平台操作指南。
- [Pro Git 中文版](https://git-scm.com/book/zh-tw/v2) — 深入 Git 原理。

## Supabase 與資料庫

- [Supabase 官方文件](https://supabase.com/docs) — PostgreSQL、Auth、Storage、Realtime 的完整說明。
- [PostgreSQL 官方文件](https://www.postgresql.org/docs/) — SQL 語法與資料庫設計。

## Docker

- [Docker 官方入門](https://docs.docker.com/get-started/) — 容器化基礎概念。
- [Dockerfile Best Practices](https://docs.docker.com/build/dockerfile/best-practices/) — 如何撰寫高效的 Dockerfile。

## AI 協作與 MCP

- [Model Context Protocol (MCP) 官方文件](https://modelcontextprotocol.io/docs) — MCP 協議的規格與實作。
- [Claude Code 官方文件](https://docs.anthropic.com/en/docs/claude-code) — Anthropic 的 CLI 編程工具。
- [Cursor 官方文檔](https://docs.cursor.com/) — AI IDE 的使用指南。

## AI Agent 架構深讀（第三階段 The Brain 主要參考）

- [AI Agent 实战：从原理到落地](https://github.com/bojieli/ai-agent-book/tree/main/book)（bojieli/ai-agent-book） — 「Agent = LLM + 上下文 + 工具」核心框架、Context Engineering、記憶與知識庫、工具設計、Coding Agent 架構、Agent 評估、多 Agent 協作，共 10 章，是 L11-L20 內容的主要靈感來源。
- [AI Agents From Zero](https://github.com/didilili/ai-agents-from-zero/tree/main)（didilili/ai-agents-from-zero） — 涵蓋 LangChain、RAG、向量資料庫、MCP、LangGraph 的實作教學，是 L15、L17、L18 的主要參考。
- [LangChain 官方文件](https://python.langchain.com/docs/introduction/) — 若想深入 RAG/Agent 框架的程式實作可延伸閱讀。
- [Anthropic: Building Effective Agents](https://www.anthropic.com/research/building-effective-agents) — 官方對 Agent 架構設計取捨的第一手說明。
